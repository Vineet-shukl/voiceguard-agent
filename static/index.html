    INTEGRATION

    VoiceGuard API

    Same-origin JSON API. Every investigation is reproducible: the report you see here is the exact payload the endpoints return.

    Endpoints

    • POST/investigateaudio or text claim → full InvestigationReport JSON
    • POST/investigate/reportsame pipeline, report-only alias
    • POST/detectacoustic deepfake detection only, with per-analyzer forensics
    • GET/agent/healthcapability & degradation probe (no key needed)
    • POST/investigate/renderreport JSON → Markdown dossier

    curl — text-only investigation

    JavaScript

    const res = await fetch('/investigate', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
    // 'X-API-Key': key   // only if this deployment sets one
  },
  body: JSON.stringify({
    transcriptOverride: 'RBI has banned all UPI transactions above 5000 rupees.',
    language: 'English',
    maxResearchRounds: 2,
    includeTrace: true
  })
});
const report = await res.json();
console.log(report.verdict.trust_score, report.verdict.risk_band);

    Authentication

    Optional. If the deployment defines an API key, send it as an X-API-Key header on every POST. Without a configured key the header is ignored. This page keeps your key in memory only — it is never stored.
